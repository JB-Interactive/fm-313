A 303-style bass line in your FM-1.

FM-313 is a free firmware that turns the M-VAVE FM-1 into an acid bass line: one voice, a squelchy diode ladder filter, accent and slide, and a step sequencer with 64 patterns. No menus to dig through. Turn the knobs and play.

What's inside

Diode ladder filter
Four coupled stages with nonlinear diode pairs, solved again for every sample. A coupling capacitor in the resonance path keeps the bass when the resonance goes up.
Accent with memory
The accent envelope runs through an RC network. Accents in a row stack up, the way the original circuit does it.
Slide
A fixed-time RC glide with no envelope retrigger. Overlapping keys slide when you play live, too.
Oscillator
A slightly bowed capacitor ramp, and a square shaped from it with tilted tops. Band-limited: aliasing stays below −73 dB.
Effects
Overdrive, distortion, fuzz and crunch, a tempo-synced ping-pong delay, reverb and an output limiter.
Built from scratch
Modelled on the publicly documented behaviour of the 303 circuit. No code or data from anyone else's firmware.

No manual needed: a help line under the scope shows what the panel does right now, every layer button opens its menu with a tap and closes it with another, and every SETUP row explains itself. The key menus draw the keyboard itself, each key labelled with what it does. Step write shows the pattern as a small piano roll: a key sets the note of the step under the cursor (SEL with it is an accent, a key still held makes a slide), the knobs edit that step, and a dice button is there if you want it. Over USB MIDI it takes notes, CCs, aftertouch and clock, records notes in realtime, and can send its notes and clock back out.

Install

  1. Open Chrome or Edge on a computer. Safari and Firefox have no Web MIDI.
  2. Charge the FM-1 and connect it directly with a USB data cable, no hub.
  3. Press “Install FM-313” and allow MIDI access. Writing takes one to two minutes.

Updating an FM-1 that already runs FM-313: it restarts into its update mode by itself, and this page goes on from there. To leave update mode without installing, switch the FM-1 off and on.

Inside a preview frame the browser often blocks MIDI. If it does, save this page as a file and open it directly in Chrome. The firmware is inside the page.
